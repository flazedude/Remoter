# Remoter 0.1.0-alpha.2

Windows x64 developer alpha. Install the Setup executable on each computer, start sharing on the host, and add its invitation on the controller.

- Windows setup wizard with installation-folder selection, shortcuts, and an uninstaller.
- Updates page checks Jack PC, GPD PC, and GitHub for the newest signed alpha release, preferring matching LAN downloads.
- Updates download and verify in the background. Stop sharing and disconnect sessions, then choose Install update to close Remoter and open the setup wizard. Paired devices and settings are retained.
- Independent LAN mirror service for Jack PC and GPD PC, using port 17846 and publisher-signed installer verification. GitHub mirrors refresh at startup and every five minutes.

Windows executables are not Authenticode signed. Windows may show an unknown-publisher prompt. Release-feed signatures authenticate subsequent updates using Remoter's embedded public key.

This release does not add unattended desktop hosting, automatic device discovery, Windows secure-desktop control, or macOS installers. Keep the desktop app open while sharing. Real-device checks between separate computers are still required.
