# Remoter 0.1.0-alpha.3

Windows x64 developer alpha.

- Add a light/dark theme toggle that remembers the choice and updates the Windows title bar. Remove slogans and simplify interface text.
- Discover computers on the LAN and connect with one click when the host enables easy LAN access. Hosts can instead require an invitation.
- Add optional clipboard text transfer and Windows audio playback to remote sessions, with host permission controls.
- Require GitHub release publication, LAN feed verification, and the full network project copy after every iteration.

- LAN sessions default to maximum JPEG quality and native display width up to 4K, with a 30 FPS target and no bandwidth throttle. Balanced and Sharper image target 30 FPS; Less bandwidth targets 15 FPS.
- The session footer shows received FPS. Frame requests remain sequential, so slow hosts or connections reduce FPS without building a capture queue. Actual performance depends on the host and network.
- Desktop sharing allows keyboard and mouse control by default. Sessions automatically enable control after the first frame when the host permits it. View-only hosts remain view-only.
- Use the normal mouse pointer instead of a crosshair. Mouse movement is coalesced at a shorter interval, and losing focus releases held input while preserving the selected control mode. Escape switches to view-only.
- Options, Updates, Devices, and Activity share the Windows title bar with Remoter and native window controls. Options and Updates remain accessible during sessions. Connection changes and update installation require disconnecting first.

Validated with TypeScript checks, unit/native tests, and the synthetic desktop/engine integration checks. Synthetic desktop throughput reached 30 FPS at 1280 × 720 on the build machine. Separate-PC capture/encoding performance and Windows secure-desktop control are not established by that test.
