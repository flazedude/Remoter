# Remoter 0.1.0-alpha.7

- Declare macOS Local Network usage so the system can ask for permission to connect to LAN computers.
- Give the packaged Mac main executable a build identity distinct from stock Electron and unrelated Electron apps before signing.
- Add a Local Network Settings action in Add device and explain macOS unreachable/permission errors with recovery steps.
- Preserve the Windows update fixes from alpha.6.

Mac packaging and local tests are verified on Apple Silicon. Developer ID signing/notarization and a signed Windows release require their publisher environments; a local Mac development DMG does not update the Windows LAN feeds.
