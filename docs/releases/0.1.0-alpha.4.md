# Remoter 0.1.0-alpha.4

Windows x64 developer alpha.

- Install verified updates while sharing or controlling a remote computer. Remove the stop-sharing requirement and keep Install update available inside an active session.
- Apply updates silently and reopen Remoter automatically. No manual disconnect, setup wizard, or closing of other programs is required. Connections pause while Remoter restarts.
- Restore sharing at the same address with its existing input, audio, clipboard, discovery, and easy-LAN permissions. Preserve existing easy-LAN pairing across an update; an ordinary stop/start still revokes it.
- Reconnect the active controlling session after the update. Store the restart handoff in OS-encrypted user data, expire it after one hour, and consume it once so ordinary launches never enable sharing.
- Leave active sharing and sessions running when update verification or handoff preparation fails. Attempt to reopen the previous executable if setup fails and display restoration failures.
- Isolate synthetic discovery tests from a user's running sharing session.

Validated with TypeScript, unit and native tests, Windows helper success/failure checks, and synthetic desktop/engine integration. Desktop checks cover installation buttons during sharing/control, encrypted restart restoration, retained view-only and LAN access, and one-use handoff consumption. Connections are briefly interrupted during file replacement; this release does not provide zero-downtime updates. Older clients retain their previous updater behavior for the one-time upgrade to this version.
