Keep Mac sharing alive when its window is closed.

- Closing the Mac window while sharing or controlling a computer hides the window and keeps the session running.
- Click Remoter in the Dock to restore the same window and session. Stop sharing or choose Remoter → Quit Remoter to end hosting explicitly.
- Retain the Windows alpha.10 cursor, streaming, input, and clipboard improvements.

The desktop smoke check closes and reopens the sharing window, verifies that an incoming client still receives synthetic frames, and verifies that explicitly quitting stops the host. It does not capture the real desktop or inject native input.
