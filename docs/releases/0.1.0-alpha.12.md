Recover video delivery when a screen stream stalls.

- Give each pending viewer frame a five-second deadline. If a frame never completes, abort that transport and reconnect automatically while preserving the selected control mode.
- Keep the actual stream error visible instead of overwriting it with the generic stalled-screen message.
- Discard a Mac capture session which times out before delivering its first frame, so later retries can start a new capture session.
- Retain alpha.11's Mac window-close behavior and the Windows alpha.10 improvements.

The viewer deadline requires this version on the controlling computer, including Windows. The Mac capture recovery requires this version on the Mac host. Regression checks suspend an isolated synthetic host while sharing stays enabled, verify the frame timeout, and resume it to verify automatic reconnection. These changes address recovery gaps; the original Windows-to-Mac interruption has not been reproduced.
