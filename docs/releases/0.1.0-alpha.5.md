# Remoter 0.1.0-alpha.5

Windows x64 developer alpha.

- Improve frame throughput by overlapping one capture with JPEG encoding and transfer. Bound prefetch to one frame, refresh stale frames, and discard prefetched frames when display or resolution changes.
- Scale Windows captures directly during the screen copy and accelerate the RGBA resize fallback. Default LAN connections to LAN · Smooth, targeting 30 FPS at up to 1080p with adaptive resolution. Keep Original · Max quality for full-resolution images and show stream width beside measured FPS.
- Add Launch on boot to sharing setup. Enable it on the target PC after starting sharing to save its address and permissions. Windows launches Remoter in the tray after sign-in and automatically resumes sharing. Closing the window keeps it running; the tray provides Open, Stop sharing, and Quit actions.
- Preserve encrypted startup settings and easy-LAN pairing across boot restoration. Stop sharing clears automatic sharing; disabling Launch on boot removes the startup entry. Startup failures open the app with an error. No desktop sharing is available before Windows sign-in.

Validated with TypeScript, unit/native tests, synthetic engine and desktop integration, startup persistence/restoration and stop-sharing checks, and opt-in real Windows capture measurements that retain no screen images. Actual FPS depends on the target PC, stream resolution, and connection; 30 FPS is a target, not a guarantee.
